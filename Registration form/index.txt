4. Understanding the most important HTML attributes
Before studying each section, understand these attributes because they appear throughout your code.
Attribute	Meaning	Example
id	Unique identifier for an element	id="email"
class	Groups elements for CSS styling	class="field"
name	Name used to identify submitted data	name="email"

Difference between id, class, and name
Consider this line:
<input type="text" id="fullName"
       name="fullName" class="field-input">


- id="fullName" uniquely identifies this input within the page.
- name="fullName" identifies the field in submitted form data.
- class="field-input" allows CSS to style it, along with other elements sharing that class.
These three attributes can have the same text, but they serve different purposes.
How labels work

<input type="email" id="email" name="email">


The for="email" attribute matches id="email". When a user clicks the label, the browser focuses the corresponding input.

Here is what their names suggest their intended purposes are:
Class	Intended purpose
wrapper	Outer page container
form-card	Main card around the form
form-header	Heading and introductory text
form-body	Main form content
section	Groups a section of fields
section-head	Section heading area
section-num	Number badge for a section
grid-2	Two-column field layout
field	Groups a label and its input
hint	Small helper text
option-group	Groups radio-button choices
option	Styles a radio or checkbox option
