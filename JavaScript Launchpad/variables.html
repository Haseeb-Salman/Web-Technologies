03 / NAMES FOR THINGS

Save it with a variable.

Variables let you store a value under a name, so you can use it again, update it, and make your code easier to understand.

▱   Beginner friendly4 min read
let

Give a value a name

Declare a variable with const or let. Use const when you don't plan to reassign the variable. Use let when you do.

✦   A couple of variablesJAVASCRIPT
const favoriteColor = "lavender";
let points = 0;
points = points + 1;
console.log(favoriteColor, points);

const doesn't mean frozen

A const variable cannot be reassigned, but if it points to an object or array, the contents of that object or array can still be changed. The binding is constant; the contents are not necessarily immutable.

✦   Updating an arrayJAVASCRIPT
const snacks = ["mango"];
snacks.push("berries"); // Allowed

let mood = "curious";
mood = "creative";      // Reassigned
✳
Start with const

A helpful default is to use const, then switch to let only when you need to reassign. Avoid var in new code; its older scoping rules can be surprising.

Choose names that explain

Variable names can use letters, digits, underscores, and dollar signs—but can't start with a digit. In JavaScript, camelCase is a common style for variables. Clear names make your code easier to revisit.

✦   Name it clearlyJAVASCRIPT
const minutesUntilLunch = 12;
const isWeekend = false;
