Operators make
things happen.

Use operators to do math, compare values, combine conditions, and update variables—all with a few familiar symbols.

±   Beginner friendly5 min read
+ − ×

Do a little math

Arithmetic operators work on numbers. The plus sign can also join strings, but template literals are often easier to read when building text.

+Addition8 + 2 → 10
-Subtraction8 - 2 → 6
*Multiplication8 * 2 → 16
/Division8 / 2 → 4
%Remainder8 % 3 → 2

Compare and get an answer

Comparison operators return a boolean: either true or false. Prefer strict equality (===) and strict inequality (!==), which compare without converting types.

✦   Ask a questionJAVASCRIPT
const age = 20;
console.log(age >= 18);      // true
console.log(age === "20"); // false

Combine conditions

Logical operators help combine boolean expressions. && means “and,” || means “or,” and ! flips a boolean.

✦   Put it togetherJAVASCRIPT
const hasTicket = true;
const doorsAreOpen = false;
console.log(hasTicket && doorsAreOpen); // false
console.log(hasTicket || doorsAreOpen); // true
✳
Remember the triple equals

5 == "5" is true because loose equality converts types. 5 === "5" is false because the types differ. Strict equality is usually the clearest choice.
