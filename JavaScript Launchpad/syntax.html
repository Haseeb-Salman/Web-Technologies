01 / THE BUILDING BLOCKS

Get the syntax right.

Syntax is the set of rules that gives your code its shape. Learn a few patterns, and you'll be reading JavaScript in no time.

⌘   Beginner friendly4 min read
;

Instructions, one at a time

A JavaScript statement is an instruction for the browser. Statements often sit on their own line. A semicolon can mark the end, though JavaScript can insert semicolons automatically in many cases—using them consistently can make code easier to scan.

✦   A first statementJAVASCRIPT
const greeting = "Hello, world!";
console.log(greeting);

Names, values, and punctuation

Names such as greeting identify values. The = sign assigns a value, while parentheses () pass information into a function. Quotes mark text, and curly braces {} group a block of code.

✳
Try to keep it readable

Use indentation inside blocks and choose clear names. The computer cares about the rules; future-you will appreciate the spacing.

Comments: notes for people

Comments explain what your code is doing. The browser ignores them when it runs your program.

✦   Two comment stylesJAVASCRIPT
// A single-line comment
const score = 10;

/* A comment can also
   span multiple lines. */

Strings in three flavors

Use single quotes or double quotes for simple text. Template literals use backticks and let you insert a value with ${expression}.

✦   Template literalJAVASCRIPT
const learner = "friend";
console.log(`Welcome, ${learner}!`);
