Values have different shapes

Every value in JavaScript has a type. The type tells you what kind of data you're working with and what you can do with it.

Check a value's type

Use typeof to ask JavaScript about many values. It returns a string describing the type.

✦   Check it outJAVASCRIPT
const city = "Tokyo";
const temperature = 22;
console.log(typeof city);        // "string"
console.log(typeof temperature); // "number"
✳
A small JavaScript quirk

typeof null returns "object" for historical reasons. When checking specifically for null, compare with === null.

Collections keep things together

Arrays are useful when order matters. Objects are useful when you want to label each piece of information.

✦   A tiny collectionJAVASCRIPT
const colors = ["coral", "mint"];
const learner = { name: "Ada", curious: true };
console.log(colors[0]);       // "coral"
console.log(learner.name); // "Ada"
