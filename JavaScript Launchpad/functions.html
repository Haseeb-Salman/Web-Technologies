05 / REUSABLE RECIPES

Say it once. Use it often.

Functions are reusable blocks of code. Give one a name, pass in information, and let it return a useful result.

ƒ   Beginner friendly5 min read
ƒ()

A function is a reusable recipe

Declare a function with the function keyword, a name, parentheses, and a block in curly braces. The code inside runs when you call the function by name.

✦   Define, then callJAVASCRIPT
function sayHello() {
  console.log("Hello there!");
}

sayHello(); // Runs the function

Pass information in

Parameters are the names in a function declaration. Arguments are the actual values you pass when you call it.

✦   Function with a parameterJAVASCRIPT
function greet(name) {
  console.log(`Hi, ${name}!`);
}

greet("Sam"); // Hi, Sam!

Return a result

Use return to send a value back from a function. Once a function returns, it has finished running.

✦   Return a valueJAVASCRIPT
function add(first, second) {
  return first + second;
}

const total = add(3, 4);
console.log(total); // 7

A shorter arrow function

Arrow functions are a compact way to write functions. They're common in modern JavaScript, especially for short callbacks and transformations.

✦   Arrow functionJAVASCRIPT
const double = (number) => number * 2;
console.log(double(6)); // 12
✳
Keep functions focused

A function that does one clear job is easier to test, reuse, and understand.
