FAQ

Frequently asked questions

Click a question to reveal the answer — using only the HTML <details> element.

Is this website using any artificial intelligence?

The website itself is pure HTML and CSS. Its content is about AI, and it was written with the help of an AI assistant — which felt appropriate for the topic!

Why are there no JavaScript files?

The project brief asked for HTML/CSS only. Everything you see — navigation, animations, the FAQ accordion and even the videos — works without a single line of JavaScript. Even the robot and the neural network are animated with pure SVG.

Some images or videos don't load — is something broken?

A few media files (2 GIFs, 2 videos, 1 photo) are loaded from public CDNs, so an internet connection is needed for them. All custom artwork is local SVG and works completely offline.

Can I use this design for my own assignment?

You can learn from the structure and CSS techniques (grid, flexbox, custom properties, animations), but submitting someone else's work as your own would be academic dishonesty — and rather ironic on a page about responsible technology.
